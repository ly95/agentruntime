# agentruntime v0.1.0 release notes

This first tagged release establishes agentruntime as a business-neutral,
embeddable model/tool kernel. It provides provider-neutral model and operation
interfaces, strict OpenAI Responses mapping, host-owned policy and execution,
approval resume, durable run and execution protocols, verification,
reconciliation, context and attachment contracts, and immutable Skills.

Compatibility and adoption notes:

- Go 1.26 or newer is required.
- Store adapters must implement the documented callbacks, atomic commits,
  identity rules, lease fencing, approval persistence, and reconciliation
  contracts; v0.1.0 does not ship a production adapter.
- Operations are offered directly from `OperationRegistry` as function tools.
  Registering a contract does not grant execution authority.
- OpenAI Responses is the only bundled provider adapter.
- Remote MCP, Codex Plugin execution, additional tool classes, and application
  infrastructure are outside this release and remain explicitly unsupported.

The release gate includes tests, race detection, vet, formatting, public API
comparison, repository contract checks, and Windows/FreeBSD compile checks.
See [ROADMAP.md](../../ROADMAP.md) for public adoption work and known limits.
